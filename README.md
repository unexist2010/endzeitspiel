# Endzeitspiel — Single-Player Prototyp

```bash
cd /workspace/endzeitspiel/prototype && python3 -m http.server 8765
```

Oberfläche: dunkles/goldenes Original-Chrome (Banner, linkes Menü, Rahmen).

Start: **Login** oder **Anmelden**. Im Spiel die Seite **Jetzt**: Ort, Aktionen, Reise, Angelegt, Ereignislog (Log bleibt auf allen Reitern).

Siehe `STATUS.md` und `../DESIGN.md`.

Die Karte nutzt `assets/map/karte-welt.jpg` als große Welt, Marker nach Biom.
